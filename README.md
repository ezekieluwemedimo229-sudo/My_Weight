
# MY WEIGHT

### A Personal Weight Tracking and Progress Monitoring App

MY WEIGHT is a weight-tracking application being developed using R and R Markdown. It is designed to help users monitor their weight, understand their Body Mass Index (BMI), set weight goals, and track their progress over time.

## Project Objectives

- Calculate BMI using a user's weight and height.
- Classify BMI into categories: Underweight, Normal weight, Overweight, and Obesity.
- Help users plan realistic weight-loss or weight-gain goals.
- Record monthly target weights and actual progress.
- Compare progress against planned goals.
- Provide progress feedback and visualisations to encourage consistency.

## Planned Features

- Personal user information and weight records.
- BMI calculation and classification.
- Goal planning with duration limits.
- Monthly weight-progress tracking.
- Progress charts and personalised encouragement.
- Data storage to support returning users.

*Note: MY WEIGHT is currently under development. Features are being implemented and tested in phases.*

## Technology Stack

- **R** — application logic and calculations.
- **R Markdown** — application development.
- **SQLite** — database storage.
- **Git and GitHub** — version control and project management.

## Project Structure

- `myweight.Rmd` — main application source file.
- `MY W.Rproj` — RStudio project file.
- `myweight.db` — SQLite database.

## Getting Started

1. Install [R](https://cran.r-project.org/).
2. Install [RStudio Desktop](https://posit.co/download/rstudio-desktop/).
3. Clone or download this repository.
4. Open `MY W.Rproj` in RStudio.
5. Open `myweight.Rmd` and follow the instructions in the application code to run the project.

Additional R packages may be required depending on the features being developed.
